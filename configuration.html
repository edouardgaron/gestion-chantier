Configuration courriel (SMTP Gmail)
Comment obtenir un « mot de passe d'application » Gmail (gratuit, 2 minutes) :
  1. La validation en deux étapes doit être activée sur le compte Google.
  2. Allez sur myaccount.google.com/apppasswords
  3. Créez un mot de passe (nom : « InnovaSpray Chantier ») et copiez les 16 caractères.
  4. Collez-le ci-dessous. Ce mot de passe n'expire pas (contrairement à l'ancien jeton n8n).
